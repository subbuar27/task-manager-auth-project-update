# Task Manager — Full-Stack Learning Project

This project follows the supplied Full-Stack Development Learning Guide.

## Stack
- Frontend: Next.js App Router, React, TypeScript, Tailwind CSS
- Forms: React Hook Form and Zod
- Data: TanStack Query and TanStack Table
- Shared user state: React Context
- Backend: Node.js, Fastify, TypeScript, Zod, JWT cookies
- Database: PostgreSQL and Prisma

## Features
- User registration, login and logout
- HttpOnly JWT cookie authentication
- Protected dashboard and task endpoints
- Per-user task ownership enforced by Fastify and Prisma
- Task listing using TanStack Table
- Create and edit task forms using React Hook Form and Zod
- Delete confirmation and TanStack Query invalidation
- PostgreSQL User and Task models managed through Prisma
